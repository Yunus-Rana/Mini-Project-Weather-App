# Weather App

A lightweight browser-based weather app that looks up current conditions for a city using the OpenWeatherMap Current Weather API.

## Features

- Search for a city by name
- View the current temperature in Celsius, humidity, and weather description
- See an emoji that reflects the current weather conditions
- Display a message when the city is missing or weather data cannot be retrieved

## Getting started

1. Get an API key from [OpenWeatherMap](https://openweathermap.org/api).
2. In `script.js`, set the `apikey` value to your API key.
3. Open `index.html` in a modern web browser.
4. Enter a city name and select **Get Weather**.

This project uses plain HTML, CSS, and JavaScript. No build step or package installation is required.


## Built with

- HTML
- CSS
- JavaScript (Fetch API)
- [OpenWeatherMap Current Weather API](https://openweathermap.org/current)
